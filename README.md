# Learning Day Obsidian Vault

A structured Obsidian knowledge vault containing community notes, presentations, speaker histories, and cross-references for **Learning Day** (107 sessions from January 2022 to October 2026).

## Vault Structure

- 🗂️ **[[Learning Day Index]]**: The central Map of Content (MOC), including key statistics, top presenters leaderboard, and chronological directory by year.
- 🎨 **[[Community & Culture]]**: Overview of the community rules (T-Shirt challenge), origin story, and creative session formats.
- 📁 **`Sessions/`**: 107 individual session notes (e.g., `Learning Day 213.md`), each with metadata frontmatter, presentation links, speaker wikilinks, and bidirectional navigation.
- 📁 **`Speakers/`**: 119 dedicated presenter profile notes (e.g., `Melvin.md`, `Ka Ho.md`, `Louis.md`), indexing every presentation given by date and session.
- 📁 **`Attachments/`**: Configured default folder for attachments and media.

## Git Sync & Backup

This vault is version-controlled via Git and configured with the `obsidian-git` community plugin for automated backups.
